# Vanish — дизайн

Дата: 2026-11-16. Рабочее название продукта: **Vanish**.

## 1. Зачем

Публичное macOS-приложение: в любом видеозвонке (Zoom, Google Meet в любом браузере, Teams, Telegram, FaceTime, Slack, Discord) пользователь может «исчезнуть» — его фигура рассыпается в пыль, остаётся пустая комната; затем так же «появиться» обратно. Идея взята из Chrome-расширения [deniza-png/snap](https://github.com/deniza-png/snap) (работает только в Google Meet в Chrome). Мы делаем то же самое для всей системы.

macOS не даёт модифицировать поток физической камеры. Поэтому Vanish публикует **виртуальную камеру «Vanish Camera»**, которую пользователь один раз выбирает в настройках видеозвонка.

## 2. Цели, не-цели, анти-цели

**Цели (v1)**
- Виртуальная камера «Vanish Camera», видна во всех приложениях, использующих системные камеры.
- Пока эффект не активен — прозрачная трансляция реальной камеры с минимальной задержкой.
- Снимок пустой комнаты с обратным отсчётом.
- Исчезновение / появление: эффект пыли (фигура распадается на частицы цвета исходных пикселей; обратная анимация — сборка). Можно выключить пыль → мгновенное исчезновение.
- Триггеры: глобальная горячая клавиша; щелчок пальцами (опционально); жест «V» (опционально).
- Установка, обновление, удаление без терминала. Подпись Developer ID + нотаризация.
- Интерфейс на русском и английском.

**Не-цели (v1)**
- Размытие/замена фона как самостоятельная функция.
- Аудиоэффекты, запись видео, несколько исходных камер одновременно.
- Windows/Linux, Mac App Store (возможен позже).
- Разрешения выше 720p.

**Анти-цели** (провал, даже если «работает»)
- Заметная задержка или подтормаживание видео в звонке.
- Участники звонка видят чёрный/замёрзший кадр без объяснения.
- Случайное исчезновение посреди звонка (ложный срабатывание жеста).
- Любые данные (видео, звук, снимок комнаты) покидают устройство.
- Камера (зелёный индикатор) включена, когда Vanish Camera никто не использует.

## 3. Ограничения

- macOS 13 Ventura и новее; Apple Silicon — основная цель, Intel — по возможности (universal binary).
- Camera Extension — системное расширение: приложение должно лежать в `/Applications`, пользователь подтверждает расширение в «Системных настройках → Основные → Объекты входа и расширения».
- Подпись: Developer ID Application (есть в связке ключей), Hardened Runtime, нотаризация. Entitlement `com.apple.developer.system-extension.install` у приложения; App Group, общая для приложения и расширения.
- Сеть — только проверка обновлений (Sparkle). Никакой аналитики.
- Код snap не используется: у его собственного кода нет лицензии. Всё пишется заново на Swift/Metal, сторонние ML-модели не нужны (Vision, SoundAnalysis — системные).

## 4. Подходы

| | Как | Плюсы | Минусы |
|---|---|---|---|
| **A (выбран)** | Приложение в строке меню делает захват камеры, сегментацию, эффект, распознавание триггеров; Camera Extension только ретранслирует готовые кадры (sink stream → source stream). Схема как у OBS Virtual Camera. | Обычные запросы доступа к камере/микрофону, полный GPU, UI для снимка комнаты, проще отлаживать. | Приложение должно быть запущено → автозапуск при входе. |
| B | Вся обработка внутри Camera Extension. | Работает без запущенного приложения. | Расширение работает от системного пользователя: доступ к камере ненадёжен, микрофон для щелчка — практически нет, нет UI, тяжело отлаживать. Для публичного продукта хрупко. |
| C | Без своей камеры: приложение показывает окно, OBS захватывает его и отдаёт через свою виртуальную камеру. | Не нужно системное расширение. | Пользователю нужно ставить и настраивать OBS. Неприемлемо для публичного продукта (был запасной путь на случай отсутствия аккаунта разработчика). |

Выбрано **A** (решение пользователя).

**Уточнение по A:** расширение не открывает реальную камеру само (иначе это вариант B). Если приложение не запущено, Vanish Camera показывает статичную заглушку «Откройте Vanish» — живой картинки без приложения не будет.

## 5. Архитектура

Два таргета:

1. **Vanish.app** — приложение в строке меню (`LSUIElement`), SwiftUI.
2. **VanishCamera.systemextension** — CMIOExtension внутри `Vanish.app/Contents/Library/SystemExtensions/`.

### 5.1 Расширение (VanishCamera)

- Одно устройство «Vanish Camera», два стрима:
  - **source** — то, что видят приложения звонков. Формат: 1280×720, 30 fps, `kCVPixelFormatType_32BGRA`.
  - **sink** — сюда приложение Vanish кладёт готовые кадры.
- Кадры из sink сразу передаются в source с актуальным временем хоста.
- Если от sink нет кадров дольше 500 мс (приложение не запущено, упало, камера отключена) — source отдаёт заглушку: тёмный кадр с логотипом и текстом «Откройте Vanish» (RU/EN по языку системы). Заглушка — PNG в бандле расширения.
- Расширение экспортирует, используется ли source каким-либо клиентом (стандартное свойство `DeviceIsRunningSomewhere`), — приложение на это подписывается.

### 5.2 Приложение (Vanish.app) — конвейер кадра

```
AVCaptureSession (выбранная физ. камера, 1280×720@30)
  → CVPixelBuffer
  → [при необходимости] Vision: маска человека, позы рук
  → Compositor (Metal) — состояние машины
  → CVPixelBuffer (IOSurface, BGRA 1280×720)
  → CMIO sink stream → расширение
```

- **Захват по требованию:** физическая камера включается, только когда Vanish Camera используется хотя бы одним клиентом, или открыто окно предпросмотра/снимка комнаты. Иначе выключена (анти-цель про индикатор камеры).
- Vanish Camera исключается из списка источников (чтобы не было петли).
- Если камера даёт не 16:9 или не 720p — масштабирование с обрезкой по центру до 1280×720.
- Зеркалирование не делаем: приложения звонков зеркалят превью сами.

### 5.3 Машина состояний эффекта

```
present ──trigger──▶ vanishing ──(анимация закончилась)──▶ vanished
   ▲                                                        │
   └──(анимация закончилась)── appearing ◀──trigger─────────┘
```

- Триггер во время анимации: разворот анимации с текущего прогресса (а не игнор).
- Триггер без снимка комнаты: не исчезаем, показываем уведомление «Сначала снимите пустую комнату».
- После любого триггера — пауза 2 с на распознавание жестов (защита от двойного срабатывания). Горячая клавиша паузой не ограничивается.

### 5.4 Сегментация

- `VNGeneratePersonSegmentationRequest`, качество `.balanced`, маска сглаживается по краю (feather) и расширяется на несколько пикселей (dilate), чтобы волосы и края рук не «торчали».
- Маска считается только когда нужна: состояния vanishing/vanished/appearing и проверка снимка комнаты. В состоянии present без включённого «V» Vision не запускается вовсе.

### 5.5 Композиция в состоянии vanished

Режим по умолчанию — **гибридный**: внутри расширенной маски человека — пиксели снимка комнаты, снаружи — живой кадр. Так в кадре остаются живыми свет, окна, часы, а пустая комната не выглядит «замороженной».

Запасной режим в настройках — **«Статичная комната»**: выводится только снимок, без живого кадра. Надёжнее, если сегментация плохо справляется (сложный фон, слабый свет).

Во время исчезновения автоэкспозиция и баланс белого фиксируются (если камера поддерживает), чтобы цвет снимка и живого кадра не расходился; после появления — возвращаются в авто.

### 5.6 Эффект пыли (Metal)

- В момент триггера из текущего кадра под маской берутся частицы: сетка с шагом 2 px (≈ до 100 тыс. частиц на 720p), у каждой цвет исходного пикселя и позиция.
- Порядок распада задаёт поле шума + направленная волна (например, справа налево), чтобы фигура рассыпалась постепенно, а не целиком.
- Частицы уносятся ветром с curl-noise, уменьшаются и гаснут. Длительность по умолчанию 1,8 с (настройка 1–3 с).
- Под частицами: кадр человека стирается по тому же порогу шума, открывая комнату (из 5.5).
- Появление — обратный процесс: частицы прилетают и собираются в маску живого кадра на момент триггера, затем показывается живой кадр.
- Если пыль выключена — кроссфейд 150 мс.
- Рендер — в выходной буфер 1280×720 без промежуточного уменьшения.

### 5.7 Снимок пустой комнаты

- Кнопка «Снять пустую комнату» → окно предпросмотра → отсчёт 5 с (пользователь выходит из кадра) → берётся 15 кадров, медиана по пикселям → PNG в контейнер App Group.
- Проверка: если на снимке найден человек (доля маски > 1 %), предупреждение и предложение переснять.
- Снимок привязан к камере (ID устройства); при смене камеры — просьба переснять.
- В предпросмотре — подсказка «не двигайте камеру и свет после снимка».

### 5.8 Триггеры

- **Горячая клавиша:** по умолчанию ⌥⇧V, переназначается. Реализация через `RegisterEventHotKey` (Carbon) — не требует разрешения «Универсальный доступ».
- **Щелчок пальцами** (выкл. по умолчанию): `SNClassifySoundRequest` со встроенным классификатором, класс `finger_snapping`, порог уверенности 0,8 (настройка «чувствительность»). Отдельный `AVAudioEngine` на вход микрофона; macOS позволяет делить микрофон с приложением звонка. Нужно разрешение на микрофон — запрашивается при включении функции.
- **Жест «V»** (выкл. по умолчанию): `VNDetectHumanHandPoseRequest` ~10 раз/с; указательный и средний пальцы вытянуты, безымянный и мизинец согнуты; жест удерживается ≥ 0,5 с.
- Порог/эвристики жестов — конфигурируемые константы, покрытые тестами на записанных позах.

### 5.9 Интерфейс

Строка меню → поповер:
- Статус: «Vanish Camera используется в: Zoom» / «Не используется» / «Расширение не установлено».
- Источник: выбор физической камеры.
- Кнопки: «Снять пустую комнату», «Исчезнуть / Появиться» (с отображением горячей клавиши).
- Переключатели: пыль, щелчок, «V»; режим комнаты (гибрид / статичная).
- «Предпросмотр» — окно с выходом Vanish Camera.
- «Настройки…»: горячая клавиша, длительность эффекта, автозапуск, проверка обновлений, удаление камеры.

**Первый запуск (онбординг):**
1. Если приложение не в `/Applications` — предложить переместить и перезапустить.
2. Установка расширения (`OSSystemExtensionRequest.activationRequest`) + пошаговая подсказка, где подтвердить в Системных настройках (с кнопкой, открывающей нужный раздел).
3. Разрешение на камеру.
4. Снимок пустой комнаты.
5. Подсказка: «Выберите Vanish Camera в настройках видео вашего приложения звонков» (Zoom/Meet/Teams/Telegram — краткие пути). Включить автозапуск (`SMAppService.mainApp`).

### 5.10 Обновление и удаление

- Sparkle 2, подпись EdDSA, appcast на GitHub Releases/Pages. Дистрибутив — нотаризованный DMG.
- При запуске новой версии приложение запрашивает замену расширения, если его версия отличается (`activationRequest` + `actionForReplacingExtension` → `.replace`).
- «Удалить Vanish Camera» в настройках → `deactivationRequest`; рекомендация сделать это перед удалением приложения.

### 5.11 Хранение

App Group-контейнер: снимок комнаты (PNG), настройки (`UserDefaults(suiteName:)`). Расширению из общих данных нужна только версия/заглушка, остальное — приложению.

## 6. Производительность (критерии приёмки)

На Apple Silicon M1, 720p@30:
- Добавленная задержка от камеры до выхода Vanish Camera ≤ 50 мс в состоянии present.
- В present без «V»: CPU приложения ≤ 15 % одного ядра; с «V» ≤ 30 %.
- Во время анимации пыли — стабильные 30 fps без пропусков.
- Расширение: CPU ≤ 3 %.

## 7. Тестирование

- Unit: машина состояний (включая разворот анимации и паузы), эвристика «V» на записанных точках рук, проверка снимка комнаты, логика «нет кадров → заглушка».
- Snapshot-тесты композитора на фиксированных кадрах и масках (гибрид/статичная, промежуточные кадры пыли с фиксированным seed).
- Ручная матрица перед релизом: Zoom, Meet (Chrome, Safari), Teams, Telegram, FaceTime, Slack, Discord; macOS 13, 14, 15, 26; встроенная камера и USB-камера; запуск/закрытие приложения во время звонка; обновление с прошлой версии.

## 8. Что решено и кем

Решения пользователя: публичный продукт; платный аккаунт Apple Developer есть; архитектура A.

Мои решения (можно оспорить): macOS 13+; Developer ID + DMG + Sparkle, без Mac App Store в v1; Swift/SwiftUI/Metal без сторонних ML-моделей; 720p@30; жесты выключены по умолчанию; гибридный режим комнаты по умолчанию; заглушка «Откройте Vanish», когда приложение не запущено; захват камеры только по требованию; RU+EN.

## 10. Решения после ревью (технические поправки)

Ревью исполнителя нашло неточности; ниже — как они решены (мои решения, пользователь разрешил не ждать):

- **Продукт бесплатный.** Лицензий, триалов и платёжных систем нет. Open source — решит пользователь позже; на код не влияет.
- **Фид обновлений:** `SUFeedURL` задаётся в Info.plist при подготовке первого релиза (скрипт релиза, подпись и нотаризация локально). До первого релиза Sparkle отключён, если ключ пуст.
- **Имя:** «Vanish» остаётся рабочим. Риск: Vanish — зарегистрированная торговая марка (средство для стирки). Bundle ID фиксируются до первого публичного релиза, после — не менять.
- **App Group не делит данные с расширением:** расширение работает от `_cmiodalassistants`, его контейнер другой. App Group нужна только как префикс `CMIOExtensionMachServiceName`. Данные приложение → расширение идут через sink stream; расширение → приложение — через кастомные свойства CMIO.
- **Заглушка двуязычная** (RU + EN на одном кадре): язык пользователя расширению недоступен.
- **«Используется ли камера»:** `DeviceIsRunningSomewhere` не подходит (sink приложения тоже считается). Расширение считает старты source-стрима в `startStream`/`stopStream` и публикует кастомное свойство (кол-во клиентов + `signingID` последнего клиента для «Используется в: Zoom»). Приложение опрашивает свойство раз в секунду.
- **Падение приложения в состоянии vanished:** участники видят заглушку (камера человека не транслируется — приватность сохранена). Состояние vanished сохраняется; при перезапуске восстанавливается без анимации (не «выпрыгиваем» в кадр).
- **Подтверждение расширения:** на macOS 13–14 — «Конфиденциальность и безопасность → Разрешить»; на 15+ — «Основные → Объекты входа и расширения». Текст онбординга зависит от версии ОС.
- **Горячая клавиша по умолчанию ⌃⌥V** (с macOS 15 Carbon-хоткеи только с ⌥/⌥⇧ отклоняются).
- **Подпись:** нужны Developer ID provisioning profiles для приложения и расширения (system extension install + App Groups). Entitlements приложения: `com.apple.developer.system-extension.install`, App Group, `com.apple.security.device.camera`, `com.apple.security.device.audio-input`. Расширение — sandboxed, App Group. Для разработки — Apple Development с автоматической подписью, приложение запускается из `/Applications`.
- **Реакции macOS 14+:** отключаем жестовые реакции (`NSCameraReactionEffectGesturesEnabledDefault = NO` в Info.plist), иначе «V» вызывает конфетти прямо в кадре. Center Stage берём под контроль приложения (`centerStageControlMode = .app`, выключен), чтобы не сбивать снимок комнаты.
- **Фиксация экспозиции/ББ** — best effort; если камера не поддерживает, гибридный режим остаётся по умолчанию, но рано проверяется на встроенной камере; при заметных швах — переключаем дефолт на «Статичная комната».
- **Гибридный режим (после живого теста):** маска скрытия = маска человека ∪ «всё, что отличается от снимка пустой комнаты» (порог 0,06 по средней разнице цвета, после выравнивания экспозиции). Иначе тени человека и разница экспозиции давали видимый силуэт. Снимок подстраивается по яркости/цвету к живому кадру (покомпонентный gain, раз в 10 кадров, EMA 0,5).
