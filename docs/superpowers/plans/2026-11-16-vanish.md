# Vanish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** macOS menu-bar app + CoreMediaIO Camera Extension that publishes "Vanish Camera" with a reversible dust "vanish" effect over the real camera.

**Architecture:** App captures the physical camera (AVFoundation), segments the person (Vision), composites passthrough / dust / empty room (Metal + Core Image), and pushes frames into the extension's sink stream; the extension relays them to its source stream or shows a bilingual stub when frames stop. Pure logic lives in a local Swift package `VanishCore` tested with `swift test`.

**Tech Stack:** Swift 6 (language mode 5), SwiftUI, AVFoundation, CoreMediaIO (CMIOExtension + C HAL API), Vision, SoundAnalysis, Metal, Core Image, Carbon hotkeys, ServiceManagement, SystemExtensions, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-16-vanish-design.md` (sections 1–10; §10 overrides earlier sections).

## Global Constraints

- Deployment target macOS 13.0; universal binary.
- Team `4D7YJ8BY8H`; app bundle id `com.vanishcam.Vanish`; extension `com.vanishcam.Vanish.CameraExtension`; app group `$(TeamIdentifierPrefix)com.vanishcam.Vanish`; mach service `$(TeamIdentifierPrefix)com.vanishcam.Vanish.CameraExtension`.
- Output format: 1280×720, 30 fps, `kCVPixelFormatType_32BGRA`.
- Device name "Vanish Camera"; stub after 500 ms without sink frames; stub text bilingual.
- Default hotkey ⌃⌥V; gesture cooldown 2 s; snap threshold 0.8; V hold ≥ 0.5 s; dust 1.8 s default (1–3 s); crossfade 150 ms when dust off.
- Room plate: 5 s countdown, 15-frame median, person-coverage > 1 % → warn.
- No network except Sparkle (Sparkle deferred until release prep — not in this plan).
- Info.plist: `NSCameraReactionEffectGesturesEnabledDefault = NO`; `LSUIElement = YES`.
- No commits unless the user asks.

## Review Focus

1. Trigger while animating → animation reverses from current progress (test in StateMachine).
2. Vanish requested with no room plate → stays present, reports `.needsRoomPlate` (test).
3. App restarted while `vanished` → restored as `vanished` without animation (test `restore`).
4. Camera delivers non-16:9 / non-720p frames → center-crop scale to 1280×720 (test `aspectFillRect`).
5. Selected camera disappears (USB unplugged) → capture falls back to default camera, no crash (manual check).

- `RoomPlateStore`: `capture(frames:) -> RoomPlateResult`, persisted PNG + camera ID in Application Support.
- `Pipeline`: owns state machine, runs capture on demand (clients>0 || preview open), 30 fps.
